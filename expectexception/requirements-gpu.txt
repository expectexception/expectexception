# torch/torchvision are pinned to a specific CUDA build rather than left as
# ">=", because this box's actual driver caps out at CUDA 12.2 (nvidia-smi:
# "CUDA Version: 12.2"), and an unpinned `torch>=2.0.0` install resolves to
# whatever is newest on PyPI - which, as of this pin, was 2.12.1+cu130,
# built against CUDA 13.0. torch silently falls back to CPU rather than
# erroring when the driver can't support the build it got (this is what
# left AI Detector / Image Upscaler running on CPU with no visible error -
# torch.cuda.is_available() just returned False), so a version drift here
# doesn't fail loudly, it just quietly stops using the GPU again.
# cu121 (CUDA 12.1) is the newest PyTorch-published build tag still under
# this driver's 12.2 ceiling (the --extra-index-url at the top of this file
# is what makes that resolvable). torchvision is pinned to the release it
# pairs with for this torch version; see
# https://github.com/pytorch/vision#installation for the compatibility
# table if bumping either.
